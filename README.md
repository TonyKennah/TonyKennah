The repo's starting "Pluckier" will all be librares or microservices related to [Pluckier](www/pluckier.co.uk) - an expert system for horse racing (private repo).  They are mostly all Java controlled by maven but you'll find TypeScript, React, HTML, CSS and plain javascript.  Dealing with data in JSON from Google Cloud Storage or from Databases like mongo and postgres.  There's also has an MCP server offering all the lastest up-to-date racing metrics for AI agents.  Where applicable a repo will have a CI/CD pipeline, some of which auto-deploy to either github packages or Render (see chatter).  Finally simple docker files allow these apps to be containerised.
